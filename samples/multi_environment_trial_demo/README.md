# 三年四点区域试验模拟原始资料包

本目录是平台 `RICE-MET-2023-2025-DEMO` 的演示资料来源。它模拟一个课题组三年、四个试验点的水稻区域试验数据被分散保存的常见情况。

## 资料结构

每个年度包含四份 Excel：

1. `区域试验材料与小区布局`：材料、别名、处理、重复、区组和小区号。
2. `区域试验环境与土壤检测`：生态区、土壤 pH、有效磷、有机质、降雨和病害压力。
3. `区域试验管理记录`：施氮量、施肥时期、灌溉和种植密度；2024 年刻意使用 `kg/ha`，其余年度使用 `kg/亩`。
4. `区域试验农艺品质记录`：产量、株高、千粒重、结实率、整精米率、垩白度、穗瘟和倒伏等级；字段名称和单位按年度变化。

## 演示用途

- 展示材料别名映射、字段映射与单位换算。
- 展示原始表格不被改写，治理后的记录可追溯到原始文件、行和字段。
- 展示在同一试验条件下的材料比较、多年多点稳定性、环境与管理关联、性状权衡及表现变差证据拆解。

所有内容均为模拟科研数据，仅用于平台演示、联调和培训，不能用于真实育种决策。
