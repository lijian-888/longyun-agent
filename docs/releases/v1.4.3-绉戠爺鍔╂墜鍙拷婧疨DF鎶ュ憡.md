# v1.4.3 科研助手可追溯 PDF 报告

发布日期：2026-07-22

## 本次目标

将“生成报告”做成农业科研助手中的自然语言能力，而不是额外独立页面。科研人员在问题中明确提出“生成报告”“导出 PDF”等请求后，系统在本轮回答完成时自动生成下载文件。

## 新增能力

- 识别明确的报告请求；普通问答不会默认生成报告。
- 回答完成后自动下载 PDF，并在回答下方保留“下载 PDF 报告”按钮，便于浏览器拦截时重试。
- PDF 固定采用七段结构：问题与范围、数据来源、数据表、图表、AI 分析、风险与局限、参考来源。
- 对区域试验问题，报告复用已保存的本地受控统计结果，包括随机区组方差分析、Tukey 多重比较、多年多点稳定性、施氮处理影响、环境关联、性状权衡或表现变差证据拆解。
- 图表只读取结构化统计结果。没有可追溯数值时，报告明确说明不生成图表，不从大模型文字中猜测或补造数据。
- 报告在请求时以内存生成并直接返回浏览器，不写入服务器文件存储，也不作为知识库资料留存。

## 数据与安全边界

- 下载接口仅允许科研人员访问自己的助手回答；会话、消息和附件仍受 PostgreSQL RLS 账号隔离。
- 报告仅引用本轮实际使用的证据卡片与本地统计运行记录；通用模型知识不会被标为平台数据来源。
- 报告中的病虫害、农药、施肥、种植及推广建议保留风险与局限提示，不能替代当地规范和专业复核。
