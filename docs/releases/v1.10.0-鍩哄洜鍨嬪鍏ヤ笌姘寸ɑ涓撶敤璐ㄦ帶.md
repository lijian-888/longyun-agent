# v1.10.0 基因型导入与水稻专用质控

## 本版目标

将连续性状 GWAS 所需的基因型数据，从“研究人员自行上传 PLINK 压缩包”的孤立步骤，改造成平台内可追溯、可复用、可治理的受控数据链路：

`原始基因型文件 -> 本地格式统一与质控 -> 样本/材料映射 -> 科研人员确认发布 -> GWAS 选择已发布版本`

本版面向水稻常规育种材料的首版演示与内网交付基础，不替代正式生物信息分析平台或大规模计算集群。

## 新增能力

### 1. 私有基因型资产工作区

- 科研人员可新建一项基因型资产并上传一个文件：`.vcf`、`.vcf.gz`，或包含 `.bed/.bim/.fam` 的 ZIP 文件。
- 浏览器采用分片上传；单项文件上限为 5 GB，不在浏览器端把完整文件读入内存。
- 原始文件保存在服务器研究数据目录，只归所属科研人员访问；页面不提供原始基因型文件下载。
- 每次原始文件重新上传、规则变化或映射修订都会形成新的版本，旧版本保留，不静默覆盖。

### 2. 水稻专用 QC 模板 v1.0

发布了默认模板“水稻常规育种材料 QC v1.0”。该模板当前用于稳定育种材料、分离群体、自然种质群体和待确认群体，并对不同群体类型给出适用范围提醒，不自动切换隐藏阈值。

| 检查项 | 首版规则 | 处理方式 |
| --- | --- | --- |
| SNP 缺失率 | 小于等于 5% | 硬过滤 |
| 样本缺失率 | 小于等于 5% | 硬过滤 |
| 最小等位基因频率 MAF | 大于等于 0.05 | 硬过滤 |
| 杂合率 | Z 分数绝对值大于 3 | 仅标记，人工复核 |
| HWE | 输出诊断结果 | 不作为首版硬过滤 |
| 同材料多样本映射 | 不允许 | 阻断发布，提交治理申请 |

### 3. 格式、坐标和文件追溯

- VCF 由本地 PLINK2 统一转换为内部 PLINK 二进制三件套；已有 PLINK ZIP 会做完整性检查。
- 自动归一化 `1`、`chr1`、`Chr1`、`chr01` 等水稻主染色体命名为 `Chr1` 至 `Chr12`。
- 非主染色体 contig 会保留在记录中并标记“参考版本待确认”，不能直接发布为正式分析版本。
- 记录原始文件 SHA-256、参考组装版本、过滤参数、输入/保留样本数和位点数、执行状态与错误原因。

### 4. 样本与材料档案映射

- QC 后的 `FID/IID` 样本可搜索并映射到既有 `breeding_material` 材料档案，例如 `SEQ2025_081 -> A-08`。
- 可下载映射模板批量填写，也可逐条检索和确认。
- 未建档材料、映射冲突、参考版本待确认和表型文件问题可提交“数据治理申请”。
- 数据处理员仅查看申请类型、说明、受影响样本和处理意见；不查看或下载科研人员的原始基因型文件。

### 5. 与连续性状 GWAS 连通

- 连续性状 GWAS 新建计划后，默认选择已发布、`analysis_ready` 的质控基因型版本。
- 绑定后，系统在服务器内部建立受控的 PLINK 快照，避免科研人员重复上传同一基因型文件。
- 平台按所选版本下载专用表型模板，预填 `FID`、`IID`、材料编码和材料名称；科研人员只需填写一个明确分析环境与连续性状值。
- 首版表型上传限定“一个材料、一个明确分析环境、一行记录”。多年多点与多重复数据应优先使用区域试验资料包治理后形成 BLUP，或走数据治理流程。
- 旧的直接上传 PLINK ZIP 入口保留为收起的历史兼容路径，新项目默认不使用。

### 6. 结果库产物

质控完成后会创建“基因型质控结果包”研究产物，包含：

- QC 摘要 PDF；
- 样本 QC CSV；
- SNP 汇总 CSV；
- 处理记录工作簿；
- 样本到材料映射模板；
- 结果 ZIP 包。

内部 PLINK 三件套仅供平台 GWAS、群体结构和后续基因组预测调用，不向浏览器直接暴露。

## 部署依赖

- `genotype-worker`：独立本地后台服务，执行 PLINK2 格式转换和 QC。
- `PLINK2`：固定在 API/worker 容器内，仅由受控工作流调用。
- PostgreSQL：保存资产、版本、任务、映射和治理申请；基因型私有记录启用 RLS。
- 本地研究数据卷：保存原始文件、内部 PLINK 文件和结果包。

## 已知边界

- 首版不支持 BGEN、PED/MAP、一个材料多 DNA 样本或技术重复。
- 首版不自动创建材料主档；未建档材料须提交数据治理申请。
- 群体类型目前影响适用提醒，尚不自动替换 QC 阈值模板。
- 大规模 VCF、联合调用、缺失填补、群体结构、遗传力和基因组预测将在后续专用技能中逐步接入。
- 正式农科院部署前仍需落实真实账号、机构级数据外发策略、备份策略、计算资源配额和原始基因型授权流程。
