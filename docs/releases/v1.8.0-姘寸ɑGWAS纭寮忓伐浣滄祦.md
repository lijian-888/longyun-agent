# v1.8.0：水稻 GWAS 确认式工作流

## 面向的第一个具体功能

平台新增“水稻连续性状 GWAS”工作台，范围固定为一个群体、一个连续性状和一条受控的关联分析流程。科研人员不需要填写命令行参数，也不能让 AI 生成或执行任意 Shell 命令。

支持的输入是：

- 一个 ZIP 包，内含同一前缀的 PLINK `.bed`、`.bim`、`.fam` 三件套；
- 一个 CSV、TSV 或 TXT 表型文件，必须有 `FID`、`IID` 与指定的连续性状列；
- 可选协变量文件，必须有 `FID`、`IID` 和至少一列协变量。

## 交互方式

工作台采用 BOLE 式的确认门槛，而不是“上传后立即计算”：

1. 新建计划时明确性状名称与参考基因组/坐标版本；
2. 上传 PLINK ZIP，平台检查三件套、PLINK 二进制标识、样本数和 SNP 数；
3. 上传表型，平台校验列名、数值性状，并计算其与 `.fam` 的 `FID/IID` 交集；
4. 可选上传协变量；
5. 平台展示默认质控阈值、PCA、混合线性模型和候选基因窗口，同时显示缺失输入和警告；
6. 仅在预检通过时，研究人员才能“确认并锁定计划”；
7. 锁定后才可提交到受控生信计算队列。

确认记录会保存输入文件 SHA-256、参考版本、固定参数、确认人和确认时间。不同登录研究人员在数据库行级安全策略下只能读取自己的计划及私有输入。

## 固定流程（Rice GWAS LMM v1）

- SNP/样本缺失率上限：`0.05`；
- MAF 下限：`0.05`；
- LD 筛选：PLINK `50 5 0.2`；
- 群体结构校正：3 个主成分；
- 关联模型：混合线性模型；
- 候选基因窗口：显著 SNP 上下游 `100 kb`；
- 水稻默认不强制 HWE 过滤：自交材料与群体结构容易使 HWE 检验产生误删，需由正式 SOP 决定是否启用。

目标输出为质控摘要、PCA 图、Manhattan 图、QQ 图，以及显著位点和候选基因表。

## 当前部署边界

本地部署现已提供完整的固定工作流。确认后，API 在私有计划目录内直接读取已锁定的 PLINK BED，执行缺失率/MAF 质控、基于质量控制标记的 PCA 和亲缘矩阵、P3D/EMMAX 式零模型近似的混合线性关联检验，并生成 JSON/TSV/PNG 结果。页面可以下载五类核心输出及完整关联结果。

为保持本机可复现性，演示实现不调用任意 Shell 命令、也不依赖某台电脑额外安装 PLINK 或 GEMMA。生产环境仍可将同一确认边界接到只允许固定版本 PLINK2/GEMMA 的内网工作节点。候选表在未配置本地水稻 GFF3 注释时输出显著 SNP 的候选窗口；配置与所选坐标版本一致的 GFF3 后，可将该列扩展为基因 ID/名称注释。
