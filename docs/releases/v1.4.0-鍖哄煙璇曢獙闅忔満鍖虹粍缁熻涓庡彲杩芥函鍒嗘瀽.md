# v1.4.0：区域试验随机区组统计与可追溯分析

## 版本定位

本版本将“区域试验资料包”纳入原有数据处理工作台。数据处理员上传三年多点的原始 Excel ZIP 文件包后，系统保留原始文件、拆分试验结构、校验设计完整性；只有通过核验并由人工确认发布的数据，才可作为农业科研助手的正式统计依据。

这不是新增一个脱离平台的分析 Demo。它是“原始资料包导入 -> 数据治理与发布 -> 农业科研助手提问 -> 可追溯统计结论”的一条正式演示链路。

## 新增能力

1. 区域试验资料包导入：支持按年份拆分的材料与小区布局、环境与土壤、管理记录、农艺品质记录等 Excel 文件打包导入。
2. 随机区组设计核验：按“试验 × 材料 × 施氮处理 × 区组”检查组合是否完整、是否有重复小区号或重复组合；不通过时禁止发布。
3. 正式统计分析：基于已发布的小区级长表数据，使用本地 `statsmodels` 执行受控模型，而不是由大模型临时编造计算。
4. 分析留痕：每次正式统计均记录问题、筛选条件、统计公式、统计引擎、源试验、参与记录数、结果和局限，便于复核。
5. 农业科研助手联动：科研人员可用自然语言触发已审核的分析方法，答案需说明数据范围、公式、证据和不可外推的边界。

## 已支持的问题类型

1. 同试验材料比较：同一年、同一试验点、同一施氮处理下，以区组为控制项进行材料产量方差分析和 Tukey 多重比较，并返回株高、千粒重、倒伏等均值。
2. 管理措施影响：同一试验内进行“材料 × 施氮”双因素随机区组方差分析，比较标准施氮与较高施氮下的产量和倒伏变化。
3. 多年多点稳定性：汇总多个有效试验环境，计算材料均值、标准差、变异系数、相对对照表现和有效环境数，并输出材料、环境及材料 × 环境互作方差分析。
4. 环境关联：以试验环境汇总值分析土壤 pH、有效磷、降雨量与结实率、千粒重、产量的关联，明确标注为相关性分析，不作为因果结论。
5. 性状权衡：比较高产、整精米率、垩白度、倒伏等性状的材料均值和相关方向。
6. 表现变差证据拆解：按材料、年份、地点、处理、环境和病害压力展示证据，区分可观察差异与尚不能证明的因果解释。

## 首版统计标准

首版统一支持“随机区组设计（RCBD）+ 材料 × 施氮处理”。同一发布试验至少需要：

- 2 个及以上区组；
- 2 个及以上材料；
- 每个材料、处理、区组组合恰好一条小区记录；
- 小区号在同一试验中不重复；
- 每个正式分析所需的表型字段已发布。

平台能核验导入记录的组合完整性，但不能仅凭 Excel 证明田间物理排列真正随机。正式科研结论仍应由试验负责人确认试验设计和田间执行情况。

## 当前边界

- 首版不替代 SPSS、R 的全部高级统计流程；AMMI、GGE 双标图、混合线性模型、显著性字母分组和审定格式 Word/PDF 报告作为下一阶段能力。
- 环境关联仅使用已入库且单位标准化的环境指标，样本量不足时会拒绝生成结论。
- 助手只读取已发布数据，不读取原始 ZIP 或待核验数据。
- 数据处理员仍须人工确认发布；原始文件始终保留且不会被覆盖。

## 验证要求

使用 `samples/multi_environment_trial_demo/水稻区域试验资料包_2023-2025_模拟数据.zip` 验证：

1. 导入后显示 12 个源文件、试验设计核验和字段换算结果；
2. 通过核验后可发布到试验、处理、环境、参试和小区级表型观测表；
3. 以已发布数据分别验证同试验比较、材料 × 施氮、稳定性、环境关联、性状权衡和表现变差证据拆解；
4. 检查 `trial_analysis_run` 是否完整记录每次正式统计分析。
