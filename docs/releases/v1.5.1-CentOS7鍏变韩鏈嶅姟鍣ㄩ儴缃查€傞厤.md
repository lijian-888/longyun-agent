# v1.5.1 - CentOS 7 共享服务器部署适配

发布日期：2026-07-24

## 变更内容

- 生产环境默认入口由宿主机 `443` 改为独立 `8443`，避免与既有 `dpanel` 容器冲突。
- `PUBLIC_PLATFORM_URL` 示例包含 `:8443`，保证 Keycloak、前端 API 和浏览器回调使用同一个正式地址。
- 新增 `deploy/compose.sh`，自动兼容 Docker Compose V2 插件和 CentOS 7 上常见的独立 `docker-compose v2` 命令。
- 预检脚本在生产入口端口已被占用时直接中止，防止首次部署错误影响其他项目。
- 备份脚本统一使用兼容 Compose 包装器。
- 新增 CentOS 7 共享服务器上线步骤，明确 DNS、证书、端口、备份、账号演示和禁止操作边界。

## 对已有功能的影响

- 不改变本地开发 `docker-compose.yml` 的行为。
- 不改变数据治理、区域试验分析、知识库、基因型质控、四个演示账号和数据隔离逻辑。
- 新服务器访问地址需要使用 `https://<院内域名>:8443`。后续取得独立 `443` 反向代理入口时，按上线步骤修改环境变量后切换。

## 风险控制

本版本不停止、不删除、不修改服务器中的其他容器、网络和数据卷；部署前必须先通过 `deploy/preflight.sh` 校验端口、证书、配置和磁盘空间。
