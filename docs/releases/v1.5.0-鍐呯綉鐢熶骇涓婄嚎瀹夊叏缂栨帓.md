# v1.5.0 内网生产上线安全编排

## 本次重大调整

本版本将原本用于本机或局域网演示的部署方式，整理为农科院内网试点可使用的生产编排。

- 新增统一 HTTPS 网关，浏览器只访问一个正式域名；不再对外暴露 Keycloak、API、数据库或解析服务端口。
- Keycloak 改为与平台同域的 `/auth` 路径，前端登录回调、JWT 签发方和 CORS 统一为正式 HTTPS 地址。
- PostgreSQL 初始化时为 Keycloak 建立独立账号与 schema；API 使用受 RLS 限制的 `rice_app` 账号，避免应用绕过数据隔离。
- API 在生产模式启动时校验 HTTPS、可信主机、CORS 和密码占位符，错误配置将阻止服务启动。
- 新增生产环境变量样例、TLS 证书目录、预检脚本、备份脚本和正式上线实施手册。

## 操作影响

- 生产环境必须使用 `deploy/.env.production`，不能继续使用含 `localhost` 或 `5183/8088` 的旧配置。
- 首次部署需要正式域名和 TLS 证书；没有院内 CA 证书时，不应向科研终端开放。
- 已有 Keycloak 数据卷更改域名时，需要在 Keycloak 管理控制台更新 Redirect URI，不能通过删除数据库卷重新初始化。
- 外部神农、Tavily 功能仍是可选项；未通过数据外发审批时应保持其 API Key 为空。
