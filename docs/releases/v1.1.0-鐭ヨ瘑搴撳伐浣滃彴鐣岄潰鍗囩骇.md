# v1.1.0 知识库工作台界面升级

发布日期：2026-07-20

## 本次调整

- 将原有知识库的表单式布局升级为资料管理工作台：顶部范围切换、左侧分类树、资料目录表格和右侧详情抽屉。
- 科研人员可在“我的知识库”和“公共知识库”之间切换；字段管理员继续只维护公共资料。
- 新增资料标题、分类、来源单位、年份、解析状态和更新时间等目录列，点击资料仅查看元数据、摘要和解析状态，不开放原文下载。
- 新增解析状态、年份、来源单位筛选，并保留标题、文件名、作者和来源的关键词搜索。
- 将上传操作改为独立弹窗，集中选择文件、目标分类及可选元数据；公共资料仍要求选择分类和填写来源单位。
- 公共资料新版本仍要求填写变更说明；管理员可继续核验本地解析预览、重新处理、发布和撤回。

## 保持不变的安全与数据边界

- 私人资料、公共资料、向量索引和原始文件的既有权限隔离逻辑不变。
- 不新增原文阅读、下载或跨用户资料共享能力。
- 文档仍由本地解析服务处理并建立索引，解析状态继续自动刷新。

## 验证

- 已执行 `frontend/npm run build`，生产构建通过。
- 部署后需要在浏览器分别检查科研人员的私人/公共资料界面，以及字段管理员的公共资料维护界面。
