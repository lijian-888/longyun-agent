# v1.3.0 区域试验资料包治理与科研问答闭环

发布日期：2026-07-21  
版本性质：本地重大功能版本，不同步推送远程仓库。

## 本次调整的核心

本版本取消了独立的“多环境试验分析 Demo”页面。区域试验能力不再是预先塞入的一组演示图表，而是纳入平台真实的数据治理流程：数据处理员上传区域试验 ZIP 资料包，平台解析并保留来源；数据处理员核验后发布入库；农业科研助手只读取这些已发布的试验级标准数据来回答科研问题。

## 新增业务流程

1. 数据处理员在“区域试验资料包”上传按年份或试验整理的 ZIP 文件包。
2. 第一版资料包支持识别四类 Excel：材料与小区布局、环境与土壤检测、栽培管理记录、农艺与品质观测记录。
3. 平台将原始 ZIP 保存在本地原始资料区，并对每一行数据记录文件名、工作表、行号等来源定位。
4. 平台把散落字段关联为“试验、环境、处理、材料参试、小区观测”五层记录；同时统一常用单位，例如 kg/ha 转换为 kg/亩，但保留原始值。
5. 资料包先进入“待数据处理员核验”，而不是自动进入科研查询库。
6. 数据处理员确认发布后，数据写入区域试验标准表；农业科研助手才能读取。

## 发布后可回答的问题

- 同一试验、同一环境和管理下，筛选产量较高且株高较低的材料。
- 比较候选材料与对照品种在多年多点的平均产量、相对增产、波动和有效环境数。
- 描述土壤 pH、有效磷、降雨量与结实率、千粒重、产量之间的样本关联。
- 比较标准施氮与较高施氮下的增产表现、株高变化和倒伏风险提示。
- 分析高产、米质和抗倒伏性状是否存在同步改善或权衡。
- 对材料表现变差的问题，并列展示土壤、天气、施氮、病害压力和观测异常等证据。

## 追溯与科学边界

- 助手证据仅来自已发布的区域试验标准数据，不读取未核验资料包，也不把隐藏的旧演示数据当作证据。
- 每次环境、管理和表现变差分析只描述关联、差异和同时出现的证据，不以观察数据直接宣称因果。
- 回答应说明试验范围、处理条件、样本数量和继续验证的必要性。

## 第一版资料包约束

- 文件包应为 ZIP，最大 50 MB、最多 80 个文件；当前主要支持 `.xlsx`。
- 同一年度和试验点应至少提供布局、环境、管理、表型四类表中的可匹配信息；无法识别的字段会进入核验提醒。
- 本版以水稻区域试验为目标。后续可增补基因型、病害图片、分子标记和更复杂的试验设计导入器，但这些尚未作为本版自动入库范围。
