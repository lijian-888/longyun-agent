# 任务 4–7 实现与验收说明

本说明对应种质资源智能解析、亲本组合辅助推荐、田间试验自动分析和育种文献与行业情报智能挖掘。所有功能均受当前登录账号的课题权限约束。

## 任务 4：种质资源智能解析

- 数据来源：当前机构业务数据库中的 `data_entity`、`data_relation`、`data_issue` 和 `ingest_batch`。
- 可动态汇总基本信息、别名、系谱、表型、环境、基因型样本和相关文献；不存在的类别显示为“缺失”，不生成推断。
- 页面与 PDF 均保留导入批次、原文件、MinIO Bucket/Object Key、文件哈希和实体标识。
- 每次解析写入 `germplasm_analysis_run`，结果只允许创建者在当前课题读取。

对应 AC4.1–AC4.5：`/api/research/intelligence/material-analysis`、解析 PDF，以及 `test_breeding_intelligence.py`。

## 任务 5：亲本组合辅助推荐

- 默认权重：产量 25%、稳定性 20%、抗倒伏 10%、抗病 10%、株高/生育期互补 10%、品质 10%、系谱风险 10%、基因型差异 5%。字段管理员可按课题调整并产生规则版本。
- 仅对实际存在的证据维度归一化加权。没有标记矩阵时绝不虚构遗传距离，该维度不计分并降低可信程度。
- 每个组合展示评分、可信程度、推荐理由、冲突/近缘风险、数据缺口、维度分和原始证据。
- 页面、PDF、CSV 均固定标注“辅助推荐，不是确定性预测结论”。

对应 AC5.1–AC5.6：`/api/research/intelligence/parent-recommendations`、规则接口、PDF/CSV，以及 `test_breeding_intelligence.py`。

## 任务 6：田间试验数据自动分析

- 科研人员显式选择已发布资料包、受控分析方法以及年份、地点、材料或处理条件。
- 支持同试验 RCBD ANOVA + Tukey、多年多点稳定性、环境关联、材料 × 管理、性状权衡和表现异常证据拆解。
- 每次运行先执行空值、IQR 疑似异常值和试验设计结构检查；异常仅提示并保留原始定位，不静默删除。
- 不满足唯一试验、区组、材料数、处理或记录数要求时返回明确原因，不生成统计结论。
- 结果保留资料包、方法版本、参数、输入记录数、来源试验、统计结果、图表、限制和运行 ID，并可下载 PDF。

对应 AC6.1–AC6.5：`/api/research/trial-analysis/*`、`trial_analysis_run`，以及 `test_trial_quality.py`。

## 任务 7：育种文献与行业情报智能挖掘

- 公共资料上传必须记录来源单位、授权依据和授权范围，字段管理员核验解析和索引后才能发布。
- 机构数据导入层中的 PDF、DOCX、TXT 可同步为待核验知识资料；原文件留在机构 Bucket，索引衍生文本记录批次、对象路径和 SHA-256。
- 支持品种、基因、性状、育种目标、试验等主题标签；回答证据卡展示资料来源、授权范围、命中位置和引用片段。
- PostgreSQL RLS 强制私人知识仅本人可检索，公共资料仅已发布版本可被科研人员检索。
- Tavily 只作为可选的近期公开资料补充；只发送通用农业主题词，不发送私有问题原文、附件或试验数据。本地知识不足时必须说明不确定性。

对应 AC7.1–AC7.5：知识库上传/同步/发布接口、BGE-M3 检索、RLS 策略和科研助手证据卡。

## 演示数据边界

`samples/institution-demo` 是明确标注的验收演示数据，包含 4 个候选材料、系谱、5 类表型证据、环境、VCF 样本和公开演示资料。`samples/multi_environment_trial_demo` 是三年四点随机区组模拟资料包。两者只用于功能验收和培训，不代表真实育种结论。
