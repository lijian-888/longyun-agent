# 试用复盘（技术试运行）

本材料是 R10 共享基础设施的技术试运行复盘，不冒充科研人员的正式业务试用反馈。2026-09-20 盘点显示：生产环境已有共享 Keycloak、前端、API、PostgreSQL 与 MinIO，业务机构为海南南繁；`institution_data_config` 记录 1 个 active 机构，AI 网关任务有 24 条历史记录，机构业务库有 60 条导入批次。此盘点仅证明现有系统状态，不代表本次新增功能已通过。

本次改造针对三类运维缺口：原备份脚本只覆盖 `rice_demo` 和两个文件卷，遗漏机构业务库、MinIO 与配置；没有独立的共享组件健康/存储策略巡检入口；缺少带防误操作校验的销毁与回滚脚本。对应措施是全库逻辑备份和校验、内网控制面、默认干运行的销毁/回滚脚本。控制面只报告服务与命名空间状态，不处理科研会话内容。

试运行后应持续观察：健康探针误报、上传期间备份一致性、MinIO 匿名策略、AI 排队数量、Keycloak 登录、文档解析负载以及异机备份可恢复性。正式业务试用还需另行收集三类角色的操作反馈、任务成功率与权限异常记录，不能由本技术材料代替。
